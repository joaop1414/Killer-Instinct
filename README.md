# ⚔️ Killer Instinct

Um jogo de batalha multiplayer focado na disputa direta entre amigos, inspirado na dinâmica de sobrevivência do modo *Matar ou Morrer* do EHR (Endless Host Roles), um mod de *Among Us*. 

O projeto foi desenvolvido no **NewCatroid** e teve seu lançamento inicial em **12/09/2026**.

---

## 🎮 Como Jogar

O objetivo principal é sobreviver e eliminar seus oponentes na arena. 
Cada sala poderá ser configurada do jeito que o anfitrião quiser.

### Controles
* **Dispositivos Móveis (Android):** Suporte nativo a telas sensíveis ao toque (Touchscreen).
* **PC:** Para jogar com teclado e mouse, é necessário utilizar um emulador Android (recomendado: **BlueStacks**).

---

## 📥 Instalação

1. Acesse a aba de **Releases** aqui no repositório.
2. Baixe o arquivo `.apk` da versão mais recente.
3. Instale o APK no seu dispositivo Android (ou emulador) e abra o jogo.

## 🚀 Próximas Atualizações (Roadmap)

Recursos e melhorias planejados para as futuras versões:

- [ ] **Suporte Multi-idioma:** Adição de suporte ao idioma Inglês (no mínimo).
- [ ] **Chat:** Implementação de um chat para os jogadores poderem conversar entre si no lobby.
- [ ] **Bloquear salas cheias:** Adição para bloquear de 2 ou mais jogadores entrarem como player 2.
- [ ] **Expulsar jogadores:** Adição para os anfitriões poderem expulsar jogadores.
- [ ] **Partidas públicas:** Sistema de encontrar partidas públicas.
- [ ] **Nome:** Ser possível dos jogadores poderem se indentificar.

## 💡 Como Enviar Sugestões ou Relatar Problemas

Ideias para novas mecânicas, melhorias de balanceamento ou relatos de bugs são muito bem-vindos!

Para enviar sua sugestão:
1. Vá até a aba **[Issues](../../issues)** no topo deste repositório.
2. Clique no botão **New Issue** (Nova Issue).
3. Escreva um título claro e descreva detalhadamente sua sugestão ou o problema encontrado.
4. Clique em **Submit new issue** para enviar.
